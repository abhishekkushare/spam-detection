How this SMS spam detector works.

SMS Spam Detection

This educational prototype reads recent SMS messages from a Twilio account and classifies each one as safe or spam.

A TensorFlow model scores the message text. A score above 0.5 is shown as spam. The rest are shown as safe messages.

Message text stays in Twilio. MySQL stores registered users and contact feedback.
